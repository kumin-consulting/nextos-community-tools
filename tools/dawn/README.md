# Dawn

The twenty minutes before sunrise: deep indigo with peach and periwinkle drifting across it, generous spacing, and the strip up at the top.

## Apply it

Open [jonkum.in/os?skin=dawn](https://www.jonkum.in/os?skin=dawn) and NextOS installs the skin and puts it on. The Skins app keeps it with the rest of yours, so you can switch back whenever you like.

## Type and layout

Typeface: `Avenir Next, Avenir, Segoe UI, sans-serif`, at the large text size.

- Strip at the top
- glass chrome
- spacious spacing
- round glyphs
- aurora sky

## What a skin is

A skin is data, not code: one JSON file saying what the ground, the windows, the strip, the glyphs, the wallpaper and every app palette should look like. It cannot run script and it cannot load anything from the network except one Google Fonts stylesheet. See [the skins guide](https://www.jonkum.in/docs/skins).
